# 🚀 المخطط الهندسي: منظومة واتساب والذكاء الاصطناعي السحابية المركزية (Sestamk Cloud AI & WhatsApp Gateway)

> **وثيقة مرجعية استراتيجية لمشروع سستمك (Sestamk POS & ERP)**  
> **الهدف:** بناء بوابة سحابية مركزية متعددة المستأجرين (Multi-Tenant) تُشغّل خدمات الواتساب المتقدمة والرد الآلي بالذكاء الاصطناعي (AI Agent) لجميع عملاء البرنامج، دون الحاجة لتثبيت Node.js أو أي برمجيات وسيطة على أجهزة الكاشير، مع حماية أسرار وPrompts الذكاء الاصطناعي بنسبة 100% من الهندسة العكسية.

---

## 1. الأهداف الاستراتيجية والمعمارية

1. **الاستغناء الكامل عن Node.js بجهاز العميل:**
   - تطبيق الكاشير سستمك يبقى تطبيق ويندوز أصيل وخفيف كنسخة مستقلة.
   - لا يتأثر بتحديثات برامج الحماية (Antivirus)، ولا يعاني من مشاكل البورتات أو صلاحيات المستخدمين.
2. **الحماية التامة للملكية الفكرية ومفاتيح الـ AI:**
   - مفاتيح الـ API (مثل OpenAI، Google Gemini، DeepSeek) تظل مخزنة داخل السيرفر السحابي فقط.
   - لا يمكن لأي محل أو مبرمج منافس فك تشفير البرنامج واستخراج توجيهات الذكاء الاصطناعي (System Prompts).
3. **بنية متعددة المستأجرين (Multi-Tenancy):**
   - خادم سحابي موحد يخدم مئات المطاعم والأنشطة التجارية في وقت واحد.
   - كل منشأة تمتلك جلسة واتساب مستقلة (`SessionID`) برقم هاتفها الخاص ومنيو الأسعار الخاص بها.
4. **صفر تكلفة تشغيلية في البداية (Zero Infrastructure Cost):**
   - استغلال السحابات المجانية للأبد لتشغيل الخدمة دون أي اشتراكات مدفوعة.

## 3. بيئة الاستضافة المجانية للأبد (Oracle Cloud Always Free)

### مواصفات الخادم السحابي المجاني:
* **مزود الخدمة:** Oracle Cloud Infrastructure (OCI) — باقة Always Free.
* **الذاكرة العشوائية (RAM):** 24 جيجابايت RAM (بمعمارية Ampere ARM).
* **المعالج (CPU):** 4 أنوية OCPU مجانية دائمة.
* **التخزين (Disk):** 200 جيجابايت NVMe SSD.
* **عنوان الشبكة:** عنوان IP عام ثابت ومجاني (Static Public IP).
* **القدرة الاستيعابية:**
  - كل جلسة واتساب عبر مكتبة Baileys تستهلك حوالي **35 إلى 50 ميجابايت رام**.
  - السيرفر المجاني يستوعب تشغيل **من 300 إلى 450 مطعماً ومحلاً متصلاً في نفس الوقت 24/7**، مع تشغيل محرك الذكاء الاصطناعي بدون أي عنق زجاجة (Bottleneck).

## 4. المكونات البرمجية ومكدس التقنيات (Tech Stack)

| المكون | التقنية | الدور البرمجي |
|---|---|---|
| **بيئة التشغيل** | Node.js 20+ مع TypeScript | أداء عالي واستهلاك موارد منخفض. |
| **محرك الواتساب** | `@whiskeysockets/baileys` | اتصال عبر بروتوكول WebSocket المباشر بدون متصفح Chromium/Puppeteer، مما يوفر 90% من استهلاك الرام ويقلل مخاطر الحظر. |
| **محرك الذكاء الاصطناعي** | LangChain / Vercel AI SDK + Gemini 1.5 Flash / DeepSeek | استيعاب اللهجة العربية والعامية المصرية، وسرعة معالجة أقل من ثانية واحدة. |
| **إدارة الجلسات** | Redis / SQLite محلي مشفر | تخزين بيانات جلسات المصادقة (Auth Credentials) بأمان. |
| **التأمين والمصادقة** | JWT + HMAC-SHA256 | التحقق من ترخيص كل برنامج سستمك متصل بالخدمة. |

## 5. قدرات موظف الذكاء الاصطناعي (AI Agent Capabilities)

1. **الرد الفوري على استفسارات المنيو والعروض:**
   - يفهم أصناف المنيو، الأحجام، والأسعار الخاصة بكل مطعم.
   - يقترح أصنافاً إضافية (Upselling) بلباقة بالعامية المصرية أو العربية الفصحى.
2. **أخذ وتسجيل الأوردرات آلياً (Conversational Ordering):**
   - يجمع الأصناف من الزبون، ويسجل العنوان والملاحظات ورقم الهاتف.
   - يرسل الأوردر مباشرة عبر Webhook إلى شاشة الكاشير والمطبخ KDS في المحل فوراً.
3. **حجز طاولات الصالة التفاعلي:**
   - يستقبل مواعيد الحجز وعدد الأفراد ويسجلها في جدول `TableReservations`.
4. **تتبع حالة الدليفري والطلبات:**
   - يفحص رقم الفاتورة ويخبر الزبون إن كان الطلب قيد التحضير أو خرج مع الطيار.

## 6. واجهات الـ REST API والمواصفات التقنية (API Specs)

### أ) إنشاء ومسح رمز الـ QR لربط رقم هاتف المحل:
* **الطلب:** `GET /api/v1/session/qr?tenant_id={ClientLicenseID}`
* **الاستجابة:**
  ```json
  {
    "success": true,
    "status": "QR_READY",
    "qr_base64": "data:image/png;base64,iVBORw0KGgo...",
    "expires_in_seconds": 45
  }
  ```

### ب) إرسال فاتورة مبيعات أو رسالة للزبون:
* **الطلب:** `POST /api/v1/messages/send`
* **الترويسات (Headers):**
  - `X-License-Key`: رقم ترخيص العميل
  - `X-Signature`: توقيع التشفير HMAC
* **جسم الطلب (Body):**
  ```json
  {
    "tenant_id": "LIC-2026-8842",
    "phone": "201012345678",
    "type": "invoice",
    "payload": {
      "invoiceNumber": "1045",
      "netTotal": 290.00,
      "items": [
        { "name": "برجر كلاسيك", "qty": 2, "price": 240.00 },
        { "name": "كولا كانز", "qty": 2, "price": 50.00 }
      ],
      "paymentType": "نقدي"
    }
  }
  ```

### ج) استقبال رسائل الزبائن وتوجيهها للـ AI (Incoming Webhook):
* يستقبل السيرفر الرسالة -> يمررها للـ AI Agent مع سياق منيو المطعم -> يُرجع الرد في محادثة الواتساب.
